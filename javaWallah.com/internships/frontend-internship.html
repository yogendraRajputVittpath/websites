THE CURRICULUM

A foundation you can build on.

Structure accessible pages with semantic elements, links, media and forms.

Create responsive layouts with reusable styles, Flexbox and CSS Grid.

Adapt interfaces across screen sizes and validate accessible forms.

Use functions, objects, DOM updates and event handling to create interactions.

Work with modules, promises, fetch and async/await.

Compose interfaces with reusable components and predictable state.

Manage effects, client-side routes and form inputs.

Track changes, build mini and major projects, test the interface and demonstrate your work.

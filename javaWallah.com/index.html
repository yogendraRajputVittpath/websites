BUILT FROM THE FUNDAMENTALS

Know what you’ll learn.

Explore the Java foundation shared by both flagship courses.

See the Full Stack curriculum

Set up the JDK and IDE, compile your first Java program, and understand how Java code runs.

Practise primitive types, operators, conditions, loops, arrays and strings.

Design classes and objects. Work with inheritance, interfaces, encapsulation and polymorphism.

Handle expected failures with try/catch, custom exceptions and clear debugging workflows.

Choose lists, sets and maps; use type-safe generics and stream operations.

Understand threads, synchronization, executors and shared-state problems.

Read and write files, manage resources and explore object serialization.

Model relational data, write SQL and connect Java applications using JDBC.

Understand beans, configuration, dependency injection and application structure.

Build web applications with controllers, services and Spring Boot configuration.

Design REST endpoints, map entities and implement persistence with repositories.

Validate inputs, learn authentication and authorization fundamentals, and use meaningful logs.

Package applications, understand environments and explore deployment workflows.

Plan, implement, test and demonstrate applications that bring the modules together.

Practise data structures, algorithms, complexity analysis and explaining your approach.
